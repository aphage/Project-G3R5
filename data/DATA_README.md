# 全球超级富豪三代人生历程数据库（v1.3）— 开放数据说明

**版本**：v1.3（2026-09；2026-10-12 勘误，见文末）
**样本**：101 个超级富豪家族 × 7 角色（本人/父/母/祖父/祖母/外公/外婆）= 707 人
**区域**：美（21）/ 欧（20）/ 中（20）/ 日（20）/ 韩（20）
**抽样**：从福布斯亿万富豪榜（含历史榜单，以纳入已故创始人）中选取；各地区内按类型多样性有目的地挑选（白手起家/继承、行业、出生年代），非随机抽样，亦非按财富排名。各类别占比只描述本样本，不能推及全体亿万富豪。
**检索方式**：各角色信息主要通过搜索引擎检索（AI 辅助检索与整理），找不到合格来源即标"缺失"；未设固定检索时长或停止规则。
**AI 使用**：资料检索与整理（含 DataPro）、第一轮编码（作者审核）、论文写作与翻译、分析代码均使用了生成式 AI 工具；每个数据格附来源 URL 与可靠度标签，可独立核查。
**维度**：9 维度（出生环境/基础教育/高等教育-专业/家庭结构/婚姻/职业轨迹/行业/财富轨迹/重大人生事件）
**变更事件**：733 条（含年份/旧值/新值/变更原因/原因分级 A-D）

## 编码原则（用户锁定口径）

1. **缺失即数据**：未记载字段明确标"缺失"，缺失分布本身是社会记录偏好的证据（性别+母系+代际三重湮没）。
2. **低教育操作定义**：= 最高教育止步于基础教育阶段（小学毕业、中学辍学）。**无学位 ≠ 低教育**；进入大学者（无论毕业与否）与完成高中者均不计入低教育。
3. **可靠度四档**：已证 / 单源 / 推断 / 缺失。
4. **事件原因分级**：A（本人公开陈述）/ B（权威记载）/ C（研究者推断）/ D（无法考证）。
5. **来源透明**：每条事实附来源 URL；中文自媒体仅作线索不作证据，以英文/本地一手源与学术源为准。

## 使用与引用

- 数据来源为公开传记、媒体报道与学术资料。本人代均为公众人物；其父母、祖辈多为非公众人物，所录信息仅限公开来源已披露的内容。
- 供学术研究使用，转载需注明来源；禁止用于商业营销或对人物的不当评价。
- 引用格式待投稿期刊确定后统一（建议同时注册数据 DOI）。

## 已知局限

- 祖辈/外祖辈缺失率高（外婆姓名可得率 2.0%，即 101 家中仅 2 家记有姓名），主要反映"记录可见性"的结构，但也受检索力度与语言影响；由于以搜索引擎检索、找不到即记缺失，缺失同时反映网络可检索性（如中文来源须经非中文独立来源交叉验证，会推高中国家族的缺失率）。
- 部分家族（KR14/KR20/JP17-JP20/EU12/EU18）填充率仅 14-22%，正式分析中是否纳入需定夺。
- 编码一致性检验：Kappa=0.628（一致率 84%，n=25）；4 个不一致样本已决议（贝当古 U→W、徐庆培 U→C 经 DataPro 补证修正）。第一轮为 AI 编码、作者审核，第二轮为作者本人盲编；两轮都有作者参与，并非完全独立，应视为一致性检验，计划请外部编码者复核。

## 勘误（2026-10-12）

- **H4 姓名可得率**：原统计把"（姓名未记载）""未记载（XX的父亲）"等占位符计为有姓名，外婆由 29.7% 修正为 2.0%，其余角色同步修正（见 full_analysis_v1.3.json 中 h4.name_rates）。
- **H3 继承者教育**：原正则统计把"辍学/在读"计为上过大学、把任何硕士计为 MBA、把欧洲人在本国读书计为留学；已改为人工复核（h3_inheritors_recode_v14.csv）。
