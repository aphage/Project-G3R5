# 全球超级富豪三代人生历程数据集 — 编码规范（v1.3，101家族）

## 1. 人物记录结构
每个家族编码 **7 人**（三代，父系+母系）：
- P1 = 本人（福布斯级超级富豪）
- P2 = 父亲
- P3 = 母亲
- P4 = 祖父（父系）
- P5 = 祖母（父系）
- P6 = 外公（母系）
- P7 = 外婆（母系）

若某人物资料完全不可得，该行仍保留，所有维度标"缺失"，并在备注说明原因。母系祖父母（P6/P7）资料通常比父系更难获得，缺失属正常，照常标"缺失"即可。

## 2. 九维度编码（每人必填）
每人沿以下 9 个维度编码，**每个数据格 = 内容 + 可靠度标签 + 来源URL**：

| 编号 | 维度 | 编码内容 |
|------|------|----------|
| D1 | 出生环境 | 出生年、出生地（精确到城市，标注城乡）、出生时家庭经济状况、时代背景 |
| D2 | 基础教育 | 小学/初中/高中，学校名称、学校类型（公立/私立/教会/军事等）、就读年限 |
| D3 | 高等教育 | 大学名称、专业、学位、就读年限、是否毕业 |
| D4 | 家庭结构 | 父母婚姻状况、兄弟姐妹排行（本人排行/总数）、主要抚养人、重大家族变故 |
| D5 | 婚姻状况 | 婚次、配偶姓名及背景、结婚/离异年份、再婚情况 |
| D6 | 职业轨迹 | 职位起止序列（年份-职位-机构），按时间排列 |
| D7 | 行业 | 主要从业行业及行业变迁（含年份） |
| D8 | 财富轨迹 | 分阶段估算（年份、估算金额、币种、估算依据） |
| D9 | 重大人生事件 | 移民/战争/金融危机/丧亲/贵人相助/重大转折等，含年份 |

## 3. 可靠度标签（每个数据单元格必填，四选一）
- **已证**：多方交叉验证（≥2个独立可靠来源一致）
- **单源**：仅一个可靠来源支撑
- **推断**：研究者基于间接证据合理推断（必须在内容中标"[推断]"）
- **缺失**：未记载（绝不编造，明确写"未记载"）

### 缺失即数据原则
"缺失"是正当取值，不是数据质量缺陷，不需要为追求填充率而降低来源标准或补充推测。缺失的分布本身是分析产出之一（反映性别、阶层、地区与时代造成的"记录可见性"差异），可行性报告必须单独呈现缺失分布。

## 4. 变更事件日志
每个维度内发生的可查证变化，记录为一条变更事件：

| 字段 | 说明 |
|------|------|
| event_id | 自动编号 E{region}{nnn} |
| person_id | 人物编号（如 US01_P1） |
| year | 发生年份（不确定标"约YYYY"或"未记载"） |
| dimension | 维度编号 D1-D9 |
| old_value | 变更前值 |
| new_value | 变更后值 |
| reason | 变更原因 |
| reason_grade | 原因来源分级（A/B/C/D） |
| source_url | 来源链接 |

### 原因来源分级
- **A** = 本人公开陈述（自传/访谈/公开演讲）
- **B** = 权威记载（学术论文/正规媒体长报道/官方传记/公司档案）
- **C** = 研究者推断（基于间接证据）
- **D** = 无法考证（标"未记载"）

## 5. 数据源层级（从高到低）
1. 家谱数据库 / 档案馆 / 官方记录（Geneastar, Geni, FamilySearch, American Ancestors, 各国国立图书馆）
2. 学术论文 / 学位论文
3. 权威传记 / 自传 / 回忆录
4. 各国维基百科（English/日本語/한국어/中文等各语言版）
5. 正规媒体长报道（NYT, WSJ, FT,  Reuters, Bloomberg, 朝日, 朝鲜日报, 财新等）
6. 自媒体（**仅作线索，不作证据**；中文材料必须交叉验证后方可引用）

### 特别警告
中文网络存在大量编造的富豪家族背景谣言（如"雷军父亲是电信高官""程维父亲是市委书记"均已被证伪）。任何中文自媒体来源的家族背景信息，必须找到至少一个非中文独立来源交叉验证，否则标"缺失"。

## 6. 输出文件格式

### 6.1 人物维度数据表（CSV）
文件名：`{region}_people.csv`

列结构（共 30 列）：
```
person_id, family, region, role, name_zh, name_en, birth_year,
D1_content, D1_reliability, D1_source,
D2_content, D2_reliability, D2_source,
D3_content, D3_reliability, D3_source,
D4_content, D4_reliability, D4_source,
D5_content, D5_reliability, D5_source,
D6_content, D6_reliability, D6_source,
D7_content, D7_reliability, D7_source,
D8_content, D8_reliability, D8_source,
D9_content, D9_reliability, D9_source,
notes
```

- role 取值：本人/父亲/母亲/祖父/祖母/外公/外婆
- 每个 content 字段中，多值用分号分隔；缺失写"未记载"
- source 字段填来源URL，多个用分号分隔；无来源写"无"
- CSV 编码：UTF-8 with BOM

### 6.2 变更事件日志（CSV）
文件名：`{region}_events.csv`

列结构：
```
event_id, person_id, year, dimension, old_value, new_value, reason, reason_grade, source_url
```

### 6.3 区域可行性备注（Markdown）
文件名：`{region}_feasibility.md`

内容：
- 每个家族的资料可得性总体评估
- 哪些维度/代际断档严重
- 使用的主要来源列表
- 遇到的特殊困难或谣言澄清

## 7. 诚实原则（最高优先级）
- 查不到就标"缺失"/"未记载"，**禁止为凑数编造**
- 禁止采信未经交叉验证的自媒体谣言
- 所有事实必须附来源URL；无URL的来源需在notes中说明来源类型
- 推断必须明确标注，不得伪装为事实
- 财富估算必须说明估算依据和年份，不得给出虚假精确值

## 7.5 分析口径：低教育的操作定义（v1.2，与用户对齐）
低教育是**分析口径**（非编码维度），用于区分"教育获得"类型。操作定义如下：

- **低教育**＝最高教育获得止步于基础教育阶段：**小学毕业或中学（初中/高中）辍学**（含小学辍学、小学毕业未入中学、中学辍学、初中毕业但后续教育被时代中断）。
- **判断标准是"基础教育是否完成/中断"，不是"是否获得大学学位"**。凡进入大学者（无论是否毕业）与完成高中者，均**不计入**低教育——**无学位 ≠ 受教育程度低**。
- 逻辑对应社会学"教育获得（attainment）vs 教育资格（qualification）"：盖茨（哈佛退学）、扎克伯格、Daniel Ek、埃里森（进入大学未毕业）属"高等教育主动退出/未完成"，非低教育。

### 低教育子类别（用于编码标注）
| 子类别 | 定义 | 示例 |
|--------|------|------|
| 小学辍学 | 小学未读完 | 松下幸之助（四年级辍学） |
| 小学毕业 | 小学毕业，未入中学或中学辍学 | 郑周永、奥尔特加 |
| 中学辍学 | 初中/高中未毕业 | 曹德旺（初一未读完） |
| 中学毕业·被剥夺 | 初中毕业但后续教育被时代中断 | 宗庆后（下乡中断） |
